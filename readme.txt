Complete Macedonia.mk newspaper: 24 articles, images, authors, pages, YouTube/TikTok, bilingual MK/EN.

== Description ==

Macedonia.mk is a complete WordPress newspaper, not an empty theme. On first activation it loads the full site:

* 24 Macedonian news articles with featured images
* 10 categories and 6 authors
* About, Contact, Embed, Saved, Privacy and Terms pages
* Primary + footer menus
* Breaking ticker, Top 5, YouTube and TikTok video rails
* MK / EN language switch for the interface and the demo articles
* JSON-LD NewsArticle + Open Graph
* Search, comments, newsletter, bookmarks

== Installation ==

1. WordPress → Appearance → Themes → Add New → Upload Theme
2. Upload `macedonia-mk.zip` → Install Now → Activate
3. The complete newspaper loads automatically (articles, images, pages, menus)
4. If the site is empty, go to Appearance → Macedonia.mk site → Load complete newspaper
5. Settings → Permalinks → Post name → Save

== Customizer ==

Appearance → Customize → Macedonia.mk newsroom:

* Tagline, weather line
* Facebook, Instagram, YouTube, TikTok profile URLs
* Breaking category slug (default: itno)
* YouTube / TikTok lists: `URL | title | duration`
