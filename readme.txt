Professional newspaper theme for Macedonian news sites. Posts, categories, featured images, menus, search, archives and video rails.

== Description ==

Macedonia.mk is a complete WordPress newspaper theme:

* Magazine homepage (hero + sidebar + category modules)
* Breaking news ticker
* YouTube and TikTok video rails
* Featured images, categories, tags, authors
* Custom logo and menus
* Search overlay + WordPress search
* Comments, newsletter, contact page
* MK / EN interface language switch
* JSON-LD NewsArticle + Open Graph

== Installation ==

1. In WordPress go to Appearance → Themes → Add New → Upload Theme
2. Upload macedonia-mk.zip and click Install Now, then Activate
3. Appearance → Customize → Macedonia.mk newsroom — set social URLs and video lists
4. Appearance → Menus — assign the primary menu (created automatically on first activate)
5. Add posts with featured images and categories. Sticky posts become the homepage hero.

Recommended permalinks: Settings → Permalinks → Post name.

== Customizer ==

* Tagline, weather line
* Facebook, Instagram, YouTube, TikTok profile URLs
* Breaking category slug (default: itno)
* YouTube / TikTok video lists: one per line as `URL | title | duration`
